## Hola, hola 👋

Este organización está enfocada en la creación de un cubo de juegos retro con compatibilidad para diferentes juegos y controladores.

## Contribuciones
El proyecto se organiza en repositorios que se encargarán de programar, diseñar o establecer diferentes componentes de un proceso más complejo de integración.
Cada componente tendrá asignado un equipo el cual deberá rendir cuentas a los demás componentes con el fin de llegar a una integración final satisfactoria.
### Grupos de trabajo
Los grupos de trabajo tendrán total libertad sobre su repositorio, sin embargo, personas externas a ese grupo podrán contribuir unicamente a través de pull requests.
### Issues
Los issues son parte fundamental del proceso de creación, un producto está lleno de ellos y es escencial que cada grupo sepa que su parte del trabajo puede contener bugs, mejoras de implementación o funcionalidades para otros grupos de trabajo.
Cualquier persona podrá publicar un issue en cualquier repositorio y podrá a su vez dar una respuesnta a ese issue a través de un pull request.
